What you're actually learning

The socket API connects application processes to transport services. The operating system manages TCP connection establishment, sequence numbers, and acknowledgments. Your application chooses the message format and when a message has been processed.

Important: This browser page simulates events for visualization. It does not open a TCP socket. The companion client.py and server.py actually communicate using TCP on localhost.
